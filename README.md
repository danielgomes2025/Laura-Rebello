# Laura Rebello Arquitetura

Site da arquiteta Laura Rebello (Maceió – AL): serviços, portfólio, avaliações do Google, briefing gamificado e contato por WhatsApp.

## Configurar antes de publicar
- **E-mail do briefing:** no `index.html`, troque `EMAIL_DESTINO` no topo do script pelo e-mail da Laura. No primeiro envio, o FormSubmit manda um e-mail de ativação para esse endereço.
- **Fotos:** hoje vêm direto do Pinterest. O ideal é salvar as originais numa pasta `img/` e trocar os links.

## Publicação
Site estático de um arquivo só. Funciona em GitHub Pages, Vercel ou Netlify sem build.
